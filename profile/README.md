# GitKraken - Visual Git Client and Repository Manager

> Explore commit history, organize branches, and review repository changes through an interactive Git interface.

GitKraken Desktop is a graphical Git client that helps developers understand repository activity and manage source control tasks visually. Its commit graph connects branches, commits, and merge history in a navigable workspace.

Use GitKraken to inspect working changes, stage files, compare revisions, manage stashes, and work with branches and linked worktrees. Repository integrations also provide access to supported pull request and issue workflows.

## Understanding the Commit Graph

![GitKraken Commit Graph Interface](https://help.gitkraken.com/wp-content/uploads/2023/06/commit-graph.png)

The commit graph provides a visual overview of repository history. Branch lines and commit nodes help explain how separate development paths relate to one another.

Select a commit to inspect its associated changes, review its message, and understand where it fits into the project history.

## Reviewing Changes Before Integration

GitKraken's working copy and diff views help identify modifications before they are committed or merged. Review the affected files, stage the relevant changes, and compare branches before integrating work.

For repositories with parallel development, worktrees can keep separate working directories organized around different branches.

## Preparing a Branch for Integration

1. Open the repository and inspect its current working state.
2. Review modified files and examine the relevant differences.
3. Stage the changes intended for the next commit.
4. Create a commit with a descriptive message.
5. Compare the working branch with its intended base.
6. Review conflicts and branch status before completing a merge.
7. Synchronize with the remote repository when appropriate.

This workflow helps keep changesets focused and makes branch integration easier to review.
